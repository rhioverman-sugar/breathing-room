Privacy and backups

Your records are stored in this browser on this device, not sent to GitHub. Clearing website data or changing devices can erase them. Export encrypted backups regularly.

Encrypted backup uses a password you choose, AES-GCM, and PBKDF2. It cannot be recovered if the password is lost. A readable JSON export is not encrypted. Browser storage itself is not encrypted by this app.
